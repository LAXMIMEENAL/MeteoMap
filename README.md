# MeteoMap

## Weather and Air Quality Monitoring Application

MeteoMap is a web application developed to provide weather and air-quality information through an interactive interface.

The project focuses on full-stack development and API integration, combining a React frontend with a Node.js backend to retrieve and present environmental information.

## Problem Statement

Weather and air-quality information is often available through different data sources. MeteoMap provides a single interface for accessing and visualising this information.

## Approach

The application follows a client-server architecture:

User
→ React Frontend
→ Node.js Backend
→ External APIs
→ Processed Data
→ User Interface

## Architecture

The React frontend handles the user interface and interaction.

The Node.js backend acts as the application layer for communicating with external APIs and processing the required information before presenting it to the frontend.

## Project Workflow

1. User provides the required location or input.
2. The frontend sends the request to the backend.
3. The backend communicates with the relevant external API.
4. The retrieved information is processed.
5. The processed information is displayed through the frontend.
